# 🟠 BALL VS BALL 3D — фан-игра на Three.js

Фан-версия роблокс-игры [Ball VS Ball](https://www.roblox.com/games/96510596525082/Ball-VS-Ball),
сделанная с нуля на **Three.js**: два шара с уникальными способностями сражаются на
парящей арене. Задача — выбить противника с платформы или снести ему всё HP.
Матч до 2 побед (best of 3). Противником управляет ИИ.

▶️ **Играть прямо в браузере:** откройте GitHub Pages этого репозитория
(Settings → Pages, или ссылка вида `https://<user>.github.io/ball-vs-ball-3d/`).

## 🎮 Управление

| Действие | Клавиши |
|---|---|
| Движение | `W A S D` / стрелки |
| Прицел | мышь |
| Рывок (удар телом) | `ПРОБЕЛ` или ЛКМ |
| Способность | `Q` или ПКМ |

## 🧠 Механики

- Физика: инерция, трение, отскоки, нокбэк, гравитация; вылет за край арены = проигрыш раунда.
- Урон от тарана зависит от скорости столкновения (рывок = сильный удар).
- Статусы: оглушение, заморозка; кулдауны рывка и способности на HUD.
- ИИ держит дистанцию под свою способность, стрейфит, добивает у края и уворачивается от центра арены.
- Частицы, трейлы, тряска камеры, всплывающий урон, синтезированный звук (WebAudio, без файлов).
- Меню и экран «VS» стилизованы под оригинал (тёмная панель, оранжевая кнопка «В БОЙ!»).

## 🚀 Запуск локально

Нужен любой статический сервер (Three.js грузится с CDN):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Либо просто откройте `index.html` в браузере с интернетом.

## 🛠 Технологии

- [Three.js r160](https://threejs.org/) (один файл `index.html`, без сборщиков)
- InstancedMesh-пул частиц, WebAudio-синтез звука, рукописная физика шаров
